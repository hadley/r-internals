8  Environments

  • R_GlobalEnv: The “global” environment
  • R_EmptyEnv: An empty environment at the root of the environment tree
  • R_BaseEnv: The base environment; formerly R_NilValue
  • R_BaseNamespace: The (fake) namespace for base
  • R_NamespaceRegistry: Registry for registered namespaces
  • R_GetCurrentEnv: Retrieve the current environment R (>= 3.6.0)
  • R_NewEnv: Create a new environment R (>= 4.1.0)

Environments are commonly called rho in the sources.

8.3 Get and set objects in environment

symbol should be a SYMSXP; environment should be an ENVSXP.

8.3.1 Get values

Note that retrieving an variable from an environment may cause an allocation because it might be an active binding.

8.3.2 Rf_findVar()

Find the value bound to a symbol in an environment and its enclosing environments.

SEXP Rf_findVar(SEXP symbol, SEXP environment);

Status: non-API (use R_getVar()) · Header: Rinternals.h · Protect: result · Errors: can throw · Since: — · R equivalent: —

Looks up symbol in environment, following up enclosing environments. Retrieving a variable from an environment may cause an allocation because it might be an active binding. Too low level to be part of the API; prefer R_getVar() or R_getVarEx() (added in R 4.5.0) in new code.

See also: Rf_findFun(), Rf_findVarInFrame3()

8.3.3 Rf_findFun()

Find the function bound to a symbol in an environment and its enclosing environments.

SEXP Rf_findFun(SEXP symbol, SEXP environment);

Status: API · Header: Rinternals.h · Protect: result · Errors: can throw · Since: — · R equivalent: —

Like Rf_findVar(), but ignores non-functions.

See also: Rf_findVar()

8.3.4 Rf_findVarInFrame3() (Rf_findVarInFrame())

Find a symbol in a single environment, without searching enclosing environments.

SEXP Rf_findVarInFrame3(SEXP env, SEXP symbol, Rboolean doGet);
SEXP Rf_findVarInFrame(SEXP env, SEXP symbol);

Status: non-API (use R_getVar()) · Header: Rinternals.h · Protect: result · Errors: can throw · Since: — · R equivalent: —

  • doGet: if TRUE, returns the value; if FALSE, just checks for presence.

Looks in a single environment. Returns R_UnboundValue if not found. Rf_findVarInFrame() is a shortcut for Rf_findVarInFrame3(rho, symbol, TRUE). Too low level to be part of the API; the R_getVar() family added in R 4.5.0 is the recommended interface: use R_getVar() or R_getVarEx() to retrieve a value and R_existsVarInFrame() to test for existence.

See also: Rf_findVar()

8.5.4 Truelength

This is almost unused. The only current use is for hash tables of environments (VECSXPs), where length is the size of the table and truelength is the number of primary slots in use, and for the reference hash tables in serialization (VECSXPs), where truelength is the number of slots in use. — R-internals

8.5.6 Hash

8.5.7 HASHTAB() (SET_HASHTAB())

Get or set the hash table of an environment.

SEXP HASHTAB(SEXP x);
void SET_HASHTAB(SEXP x, SEXP v);

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

Hashing is principally designed for fast searching of environments, which are from time to time added to but rarely deleted from, so items are not actually deleted but have their value set to R_UnboundValue. — R-Internals SET_HASHTAB() is not part of the API; create hash-based environments with the constructor R_NewEnv() instead.

See also: HASHASH(), HASHVALUE()

Code from lobstr should help me understand how they work:

int FrameSize(SEXP frame) {
  int count = 0;

  for(SEXP cur = frame; cur != R_NilValue; cur = CDR(cur)) {
    SEXP obj = CAR(cur)
    if (obj != R_UnboundValue)
      count++;
  }
  return count;
}

int HashTableSize(SEXP table) {
  int count = 0;
  int n = Rf_length(table);
  for (int i = 0; i < n; ++i)
    count += FrameSize(VECTOR_ELT(table, i));
  return count;
}

int envlength(SEXP x) {
  bool isHashed = HASHTAB(x) != R_NilValue;
  return isHashed ? HashTableSize(HASHTAB(x)) : FrameSize(FRAME(x));
}
