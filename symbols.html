9  Symbols

9.1 Test

9.1.1 Rf_isSymbol()

Test whether an object is a symbol.

Rboolean Rf_isSymbol(SEXP s);

Status: API · Header: Rinternals.h · Protect: n/a · Errors: never · Since: — · R equivalent: is.symbol()

9.2 Create

If symbol exists, return it; otherwise create it. SYMSXPs don’t need to be protected because symbols are not currently reclaimed by the garbage collector. If you are using a symbol many times, it may be worth caching it to avoid repeated lookups.

9.2.1 Rf_install() (Rf_installChar())

Create the symbol for a name, returning the existing symbol if already present.

SEXP Rf_install(const char *);
SEXP Rf_installChar(SEXP);

Status: API · Header: Rinternals.h · Protect: not needed · Errors: can throw · Since: — · R equivalent: as.name()

Symbols are never garbage collected, so SYMSXPs don’t need to be protected. Cache frequently used symbols to avoid repeated lookups.

9.3 Missing symbol

R_MissingArg represents the missing/empty symbol, i.e. the second argument in this call f(x, ).

9.3.1 R_MissingArg()

Access the missing/empty symbol.

SEXP R_MissingArg;

Status: API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

Used as the second argument in a call like f(x, ).

9.4 Predefined symbols

  • R_dot_defined: “.defined”
  • R_dot_Method: “.Method”
  • R_dot_packageName: “.packageName”
  • R_dot_target: “.target”
  • R_BaseSymbol: “base”
  • R_BraceSymbol: “{”
  • R_Bracket2Symbol: “[[”

  • R_ClassSymbol: “class”
  • R_DeviceSymbol: “.Device”
  • R_DimNamesSymbol: “dimnames”
  • R_DimSymbol: “dim”
  • R_DollarSymbol: “$”

9.5 Internals

9.5.1 PRINTNAME() (SET_PRINTNAME())

Get or set the print name of a symbol.

SEXP (PRINTNAME)(SEXP x);
void SET_PRINTNAME(SEXP x, SEXP v);

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

The value of the symbol, as a CHARSXP. Use CHAR(PRINTNAME(x)) to get the name as a const char*.
