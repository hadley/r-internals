11  Functions

11.1 Testing functions

FUNSXP is an abstract union type.

11.1.1 Rf_isFunction() (Rf_isPrimitive())

Test whether an object is a function or a primitive function.

Rboolean Rf_isFunction(SEXP);
Rboolean Rf_isPrimitive(SEXP);

Status: API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: is.function()

FUNSXP is an abstract union type.

11.2 Internals

11.2.1 FORMALS() (BODY(), CLOENV())

Access the formal arguments, body, or environment of a closure.

SEXP (FORMALS)(SEXP x);
SEXP (BODY)(SEXP x);
SEXP (CLOENV)(SEXP x);

Status: non-API (use R_ClosureFormals()) · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: formals()

Accessors for the components of a closure (CLOSXP). Use R_ClosureFormals(), R_ClosureBody(), and R_ClosureEnv() (added in R 4.5.0) instead.

See also: R_ClosureBody(), R_ClosureEnv()

11.2.2 SET_FORMALS() (SET_BODY(), SET_CLOENV())

Set the formal arguments, body, or environment of a closure.

void SET_FORMALS(SEXP x, SEXP v);
void SET_BODY(SEXP x, SEXP v);
void SET_CLOENV(SEXP x, SEXP v);

Status: non-API (use R_mkClosure()) · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: formals<-()

Setters for the components of a closure (CLOSXP). Use the constructor R_mkClosure() (added in R 4.5.0) to create a closure instead of allocating and mutating one.

11.2.3 RDEBUG() (RSTEP(), RTRACE())

Query the debug, step, or trace flags of a closure.

int  (RDEBUG)(SEXP x);
int  (RSTEP)(SEXP x);
int  (RTRACE)(SEXP x);

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

Internal macros for querying closure debugging flags.

11.2.4 SET_RDEBUG() (SET_RSTEP(), SET_RTRACE())

Set the debug, step, or trace flags of a closure.

void (SET_RDEBUG)(SEXP x, int v);
void (SET_RSTEP)(SEXP x, int v);
void (SET_RTRACE)(SEXP x, int v);

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

Internal macros for setting closure debugging flags.

11.3 Promises (PROMSXP)

11.3.1 R_UnboundValue()

Access the unbound-value marker constant.

LibExtern SEXP  R_UnboundValue;     /* Unbound marker */

Status: API · Header: Rinternals.h · Protect: n/a · Errors: never · Since: — · R equivalent: —

R_UnboundValue marks an unbound symbol or an unread promise value.

See also: R_MissingArg()

11.3.2 PRCODE() (PRENV(), PRVALUE())

Access the code, environment, or value of a promise.

SEXP (PRCODE)(SEXP x);
SEXP (PRENV)(SEXP x);
SEXP (PRVALUE)(SEXP x);

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

Accessors for the components of a promise (PROMSXP). Use the binding access API added in R 4.6.0 instead: R_GetBindingType(), R_ForcedBindingExpression(), R_DelayedBindingExpression(), and R_DelayedBindingEnvironment().

See also: R_GetBindingType()

11.3.3 PRSEEN() (SET_PRSEEN())

Query or set the seen flag of a promise.

int  (PRSEEN)(SEXP x);
void (SET_PRSEEN)(SEXP x, int v);
void SET_PRSEEN(SEXP x, int v);

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

Accessors for the seen flag of a promise (PROMSXP), used to detect recursive promise evaluation.

11.3.4 SET_PRENV() (SET_PRVALUE(), SET_PRCODE())

Set the environment, value, or code of a promise.

void SET_PRENV(SEXP x, SEXP v);
void SET_PRVALUE(SEXP x, SEXP v);
void SET_PRCODE(SEXP x, SEXP v);

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

Setters for the components of a promise (PROMSXP). Use the binding access API added in R 4.6.0 instead: R_MakeForcedBinding(), R_MakeDelayedBinding(), and R_MakeMissingBinding().

See also: R_MakeDelayedBinding()

11.4 Srcrefs

11.4.1 R_Srcref()

Access the current srcref, for debuggers.

LibExtern SEXP  R_Srcref;           /* Current srcref, for debuggers */

Status: API · Header: Rinternals.h · Protect: n/a · Errors: never · Since: — · R equivalent: —

The current srcref, for debuggers.

11.4.2 R_GetCurrentSrcref() (R_GetSrcFilename())

Get the current srcref or the source filename of a srcref.

SEXP R_GetCurrentSrcref(int);
SEXP R_GetSrcFilename(SEXP);

Status: API · Header: Rinternals.h · Protect: result · Errors: never · Since: — · R equivalent: —

R_GetCurrentSrcref returns the current srcref and R_GetSrcFilename returns the source filename for a srcref.
