21  Utilities

Assorted entry points that don’t fit elsewhere: options, parsing, and file paths. Most are declared in R_ext/Utils.h (included by <R.h>). For sorting, ordering, matching, and duplication, see Vectors; for string searching, see Strings.

21.1 Testing

21.1.1 R_compute_identical()

Test whether two objects are identical.

Rboolean R_compute_identical(SEXP, SEXP, int);

Status: API · Header: Rinternals.h · Protect: n/a · Errors: can throw · Since: — · R equivalent: identical()

The third argument is a bitmask of flags for non-default options (set a bit to get the FALSE behaviour): 1 = !NUM_EQ, 2 = !SINGLE_NA, 4 = !ATTR_AS_SET, 8 = !IGNORE_BYTECODE, 16 = !IGNORE_ENV, 32 = !IGNORE_SRCREF. R’s identical() default corresponds to 16.

21.2 Options

21.2.1 Rf_GetOption() (Rf_GetOption1())

Retrieve the value of an R option.

SEXP Rf_GetOption(SEXP, SEXP);
SEXP Rf_GetOption1(SEXP);

Status: API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: getOption()

Use Rf_GetOption1(); Rf_GetOption() is kept for compatibility.

See also: Rf_GetOptionDigits()

21.2.2 Rf_GetOptionDigits() (Rf_GetOptionWidth())

Retrieve the digits or width option.

int Rf_GetOptionDigits(void);
int Rf_GetOptionWidth(void);

Status: API · Header: Rinternals.h · Protect: n/a · Errors: never · Since: — · R equivalent: getOption()

See also: Rf_GetOption()

21.3 Numeric parsing

R_atof()/R_strtod() exist because the C library equivalents are locale-dependent: R’s versions always use . as the decimal point and recognise "NA".

21.3.1 R_atof() (R_strtod())

Convert a string to a double.

double R_atof(const char *str);
double R_strtod(const char *c, char **end);

Status: API · Header: R_ext/Utils.h · Protect: n/a · Errors: never · Since: — · R equivalent: as.numeric()

These two are guaranteed to use ‘.’ as the decimal point, and to accept “NA”.

21.4 Files and system

21.4.1 R_popen() (R_system())

Open a pipe or run a command in a shell.

#ifdef HAVE_POPEN
FILE *R_popen(const char *, const char *);
#endif
int R_system(const char *);

Status: API · Header: Rinternals.h · Protect: n/a · Errors: never · Since: — · R equivalent: system()

R_popen() is only available when HAVE_POPEN is defined.

21.4.2 R_tmpnam() (R_tmpnam2(), R_free_tmpnam())

Create a name for a temporary file.

char *R_tmpnam(const char *prefix, const char *tempdir);
char *R_tmpnam2(const char *prefix, const char *tempdir, const char *fileext);
void R_free_tmpnam(char *name);

Status: API · Header: R_ext/Utils.h · Protect: n/a · Errors: can throw · Since: — · R equivalent: tempfile()

The returned string is dynamically allocated; free it with R_free_tmpnam() (not free()). A NULL prefix or extension is replaced by "".

21.5 Platform information

Follows WRE §6.17, Platform and version information closely.

A few macros help write platform-aware code: USING_R confirms the code is being compiled for R, and Rconfig.h (included by <R.h>) defines platform macros such as WORDS_BIGENDIAN — but note these describe the compiler that built R, not necessarily yours. For compile-time R version checks (R_VERSION, R_Version()), see R version. If you use alloca, define it portably via Rconfig.h’s HAVE_ALLOCA_H as shown in WRE §6.17.
