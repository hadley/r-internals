21.1.5 R_PromiseExpr() (R_ClosureExpr(), PREXPR(), BODY_EXPR())

Get the unevaluated expression of a promise or the body expression of a closure.

SEXP R_PromiseExpr(SEXP);
SEXP R_ClosureExpr(SEXP);
#define PREXPR(e) R_PromiseExpr(e)
#define BODY_EXPR(e) R_ClosureExpr(e)

Status: non-API · Header: Rinternals.h · Protect: not needed · Errors: never · Since: — · R equivalent: —

R_PromiseExpr() is not part of the API; use the binding access API added in R 4.6.0 (e.g. R_DelayedBindingExpression()) to inspect promise bindings.

21.2 Sorting

21.2.1 R_qsort() (R_qsort_I(), R_qsort_int(), R_qsort_int_I())

Sort a numeric array in place using quicksort.

void R_qsort    (double *v,         size_t i, size_t j);
void R_qsort_I  (double *v, int *II, int i, int j);
void R_qsort_int  (int *iv,         size_t i, size_t j);
void R_qsort_int_I(int *iv, int *II, int i, int j);

Status: API · Header: R_ext/Utils.h · Protect: n/a · Errors: never · Since: — · R equivalent: sort()

The dummy index argument is renamed to II to avoid problems with g++ on Solaris.

See also: R_isort(), R_orderVector()

21.2.6 R_orderVector() (R_orderVector1())

Compute an ordering permutation into an index array.

void R_orderVector (int *indx, int n, SEXP arglist, Rboolean nalast, Rboolean decreasing);
void R_orderVector1(int *indx, int n, SEXP x,       Rboolean nalast, Rboolean decreasing);

Status: API · Header: Rinternals.h · Protect: n/a · Errors: can throw · Since: — · R equivalent: order()

C equivalent of order(..., na.last, decreasing); build arglist with Rf_lang2() or Rf_lang3(). R_orderVector1() is the single-vector version, equivalent to order(x, na.last, decreasing).

See also: R_qsort()

21.3 Misc

21.3.1 Rf_allocSExp()

Allocate a non-vector SEXP of the given type.

SEXP Rf_allocSExp(SEXPTYPE);

Status: non-API · Header: Rinternals.h · Protect: result · Errors: can throw · Since: — · R equivalent: —

Not part of the API, as it exposes internal structure that might need to change. Use an appropriate constructor instead: R_NewEnv() for environments, R_mkClosure() for closures (added in R 4.5.0), or Rf_allocLang() for call expressions (added in R 4.4.1).

See also: R_NewEnv()

21.3.20 R_compute_identical()

Test whether two objects are identical.

Rboolean R_compute_identical(SEXP, SEXP, int);

Status: API · Header: Rinternals.h · Protect: n/a · Errors: can throw · Since: — · R equivalent: identical()

The third argument is a bitmask of flags for non-default options (set a bit to get the FALSE behaviour): 1 = !NUM_EQ, 2 = !SINGLE_NA, 4 = !ATTR_AS_SET, 8 = !IGNORE_BYTECODE, 16 = !IGNORE_ENV, 32 = !IGNORE_SRCREF. R’s identical() default corresponds to 16.
